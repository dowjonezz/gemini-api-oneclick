Интерфейс

Новый dashboard не зависит от внешних шрифтов, поддерживает светлую и тёмную темы и не отображает CJK-строки из legacy backend.

Статистика лимитов читается напрямую из служебного Gemini Web RPC GetUsageInfo и кешируется на 60 секунд. Это не текстовый prompt и не создаёт новый Gemini-чат.
